# PufferGo 扩展程序 — 隐私政策

**最后更新：2026 年 6 月 24 日**

[English Version / 英文版本](./chrome-extension-privacy.html)

## 关于我们

PufferGo 是一款 Chrome 扩展程序，帮助外贸企业直接在浏览器中搭建和管理 WordPress 网站。本隐私政策说明我们收集哪些数据、原因以及处理方式。

开发者联系方式：tech@puffergo.com

---

## 我们访问哪些数据及原因

### 1. 浏览内容（仅限当前标签页）

**内容：** 使用区块克隆工具时，扩展程序会截取您当前浏览页面的截图，并提取您所选元素的 HTML/CSS。

**原因：** 这些数据将发送至我们的服务器（`api.puffergo.com`），仅用于为您的站点生成匹配的 WordPress 区块组件，不会被存储、索引或用于任何其他目的。

**时机：** 仅在您主动点击"克隆区块"时触发。扩展程序不会被动监控您的浏览行为。

---

### 2. 账户与身份验证数据

**内容：** 连接 PufferGo 账户时，浏览器会打开 puffergo.com 供您登录。授权完成后，API 密钥将返回扩展程序并存储在 Chrome 本地存储中。

**原因：** 用于验证您的订阅状态，并启用与账户绑定的功能（AI 生成额度、站点管理等）。

**我们服务器接收的内容：** 您的 PufferGo 账户 ID 和许可证密钥。我们不会接收或存储您的 Google 凭据或浏览器密码。

---

### 3. 第三方 API 凭据（Cloudflare、Hostinger、WordPress）

**内容：** 建站过程中，您可能需要输入 Cloudflare 或 Hostinger 的 API Token。这些 Token 仅存储在您设备上 Chrome 扩展程序的本地存储中。

**原因：** 扩展程序使用这些 Token，通过各服务商的官方 API 代您配置 DNS、SSL 和托管设置。

**重要说明：** 这些凭据绝不会经过 PufferGo 的服务器。所有 API 调用均从您的浏览器直接发送至第三方服务商。

---

### 4. 匿名使用分析（可选，需主动开启）

**内容：** 若您选择开启分析功能，我们会收集匿名化的事件数据：任务开始/完成/失败、耗时、错误类别。不包含任何 URL、页面内容、个人标识符或浏览历史。

**原因：** 用于提升扩展程序的稳定性，并了解哪些功能最受用户欢迎。

**方式：** 我们使用 PostHog，并已关闭自动捕获。每位用户被分配一个随机匿名 ID。您可随时在扩展程序设置中关闭分析功能。分析功能**默认关闭**。

---

### 5. 划词翻译（默认关闭）

**内容：** 开启翻译功能后，当您在网页上选中文字时，选中的文字及页面上下文（页面标题、描述、URL）将直接发送至您在扩展程序设置中配置的第三方 LLM 服务商（如 OpenAI、Anthropic）。

**原因：** 为您提供 AI 驱动的划词翻译，翻译成您指定的目标语言。

**时机：** 仅在您手动开启翻译功能，且主动选中文字并点击翻译按钮时触发。该功能**默认关闭**，需手动启用。不会被动发送任何文字。

**重要说明：** 翻译请求从您的浏览器直接发送至您配置的 LLM 服务商，使用您自己的 API 密钥。PufferGo 的服务器不参与其中，也不会接触您的文字内容。

---

## 我们不会做的事

- 不会将您的数据出售给任何第三方
- 不会追踪您的浏览历史
- 不会读取您的密码、表单输入或私信
- 不会将您的数据用于广告目的
- 不会在生成区块后留存截图或 HTML 内容

---

## 数据存储

| 数据类型 | 存储位置 |
|---------|---------|
| 扩展程序设置、API Token、建站配置 | Chrome 本地存储（仅在您的设备上） |
| PufferGo 账户会话 Token | Chrome 本地存储（仅在您的设备上） |
| 匿名分析 ID | Chrome 本地存储 + PostHog（匿名化） |
| 区块克隆的截图 / HTML | 传输至 `api.puffergo.com`，不留存 |

---

## 您的权利

卸载扩展程序或在 Chrome 扩展程序设置中清除扩展数据，即可删除所有本地存储的数据。如需删除我们服务器上存储的数据，请发送邮件至 tech@puffergo.com 提出申请。
