## Frequently Asked Questions

### What does PufferGo do?

PufferGo is a Chrome extension that helps foreign trade businesses quickly build and manage WordPress websites. It automates common tasks such as site setup, page cloning, and content configuration.

### Which platforms are supported?

PufferGo currently supports WordPress sites hosted on Cloudflare and Hostinger. Support for additional hosting providers is planned for future releases.

### How do I install PufferGo?

1. Install the extension from the Chrome Web Store.
2. Click the PufferGo icon in your browser toolbar to open the side panel.
3. Follow the on-screen setup guide to connect your hosting account.

### The extension is not working — what should I do?

- Make sure you are using a supported browser (Chrome or Edge).
- Reload the extension from `chrome://extensions/` or reinstall it.
- Clear your browser cache and try again.
- If the issue persists, please open a GitHub Issue or email us with a description of the problem and your browser version.

### Can I request a new feature?

Yes! We welcome feature requests via [GitHub Issues](https://github.com/puffergo/puffergo-extension/issues). Please describe your use case and the problem you are trying to solve.

## Bug Reports

When reporting a bug, please include:

- Browser name and version
- Extension version (visible in `chrome://extensions/`)
- Steps to reproduce the issue
- Expected vs. actual behavior
- Screenshots or error messages if available
