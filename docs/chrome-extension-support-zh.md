## 常见问题

### PufferGo 是做什么的？

PufferGo 是一款 Chrome 扩展程序，帮助外贸企业快速搭建和管理 WordPress 网站。它可以自动完成建站、页面克隆、内容配置等常见操作。

### 支持哪些平台？

PufferGo 目前支持托管在 Cloudflare 和 Hostinger 上的 WordPress 网站，后续版本将陆续支持更多主机服务商。

### 如何安装 PufferGo？

1. 从 Chrome 应用商店安装扩展程序。
2. 点击浏览器工具栏中的 PufferGo 图标，打开侧边栏。
3. 按照页面提示完成主机账号的连接与建站设置。

### 扩展程序无法正常使用怎么办？

- 请确认您使用的是受支持的浏览器（Chrome 或 Edge）。
- 在 `chrome://extensions/` 页面重新加载或重新安装扩展程序。
- 清除浏览器缓存后重试。
- 若问题仍存在，请通过 GitHub Issues 或邮件向我们反馈，并附上问题描述及浏览器版本信息。
